# 직장에서 살아남기

> 환생 반복형 직장인 시뮬레이션 클리커. **1회차는 무조건 못 깬다.**

**▶ [플레이하기](https://minmi0123.github.io/salaryman-survival/)**

단일 HTML 파일 하나. 설치도 빌드도 서버도 필요 없습니다. 파일을 브라우저로 열면 바로 시작됩니다.

---

## 어떤 게임인가

하루를 블록 단위로 클릭해 넘기며 **멘탈 · 건강 · 업무 · 돈** 네 게이지를 저글링합니다.
어느 하나라도 무너지면 배드엔딩. 죽으면 유령이 되어 스킬포인트만 갖고 환생합니다.

```
정규시간에 처리할 수 있는 양 < 하루에 배정되는 업무량

→ 매일 야근하거나, 매일 이월시키거나 둘 중 하나
→ 야근하면 멘탈·건강이 며칠 안에 0
→ 이월하면 업무가 며칠 안에 100 초과
어느 쪽이든 죽는다.
```

이 산수가 이 게임의 전부입니다. 스킬이 조금씩 수지를 밀어주고, 그만큼 더 오래 버팁니다.

## 핵심 설계

### 경고는 페널티가 아니라 자원입니다

게이지가 바닥나면 경고를 하나 받고 **그 게이지가 완전히 회복**됩니다.

```
멘탈 0  →  경고 +1  →  멘탈 100 회복
```

경고 예산은 3개. 이걸 언제 쓸지가 곧 회차 운영입니다.
약·담배 같은 아이템은 경고를 안 쓰고 회복시켜주니, **돈이 곧 생존 시간**이 됩니다.

### 돈은 두 곳에서 경쟁합니다

| 용도 | |
|------|---|
| 생존 | 약·담배·AI·부적을 사서 경고를 아낀다 |
| 엔딩 | 모든 트리 엔딩 노드가 돈 조건을 요구한다 |

쟁여둘수록 엔딩이 멀어집니다. 그래서 아이템 보유 한도가 따로 필요 없습니다.

### 스킬은 선택지를 열어줍니다

1회차 아침에는 `[바로 출근하기]` 하나뿐입니다. 스킬을 찍으면 하나씩 열립니다.

| 선택지 | 해금 |
|--------|------|
| 바로 출근하기 | 기본 |
| 커피 사먹기 | 업무 계열 SP 3 |
| 더자기 | 자기관리 계열 SP 3 |
| 한약 | 자기관리 계열 SP 3 |

성장이 숫자가 아니라 **"할 수 있는 일"** 로 보입니다.

## 스킬트리

네 계열이 서로 다른 축을 담당합니다.

| 계열 | 담당 | 서브트리 |
|------|------|----------|
| 업무 | 업무 게이지 | 사장님(건강·돈) / 팀장님(멘탈·업무) |
| 부업알바 | 돈 | 돈많은백수(알바) / 크리에이터(부업) |
| 아이템 | 경고 예산 | 검은손(자가조달) / 사업가(유통) |
| 자기관리 | 회복률 | 운동(평일형) / 기도(주말형) |

어느 계열로 시작하든 첫 엔딩까지의 거리가 같도록 맞춰져 있습니다.

## 실행

```bash
# 그냥 열면 됩니다
index.html

# 밸런스 시뮬레이터
node sim.js
```

## sim.js

DOM 없이 게임 로직만 복제한 밸런스 검증 스크립트입니다.
전략 5종 × 빌드 10종을 수십 회씩 돌려 다음을 측정합니다.

- 1회차 생존 일수
- SP 획득 곡선이 실제로 가속하는가
- 배드엔딩 4종이 골고루 나오는가 (한 종류만 나오면 나머지 축이 죽은 것)
- 특정 빌드가 다른 빌드를 압도하는가

이걸로 잡은 결함들:

| 증상 | 원인 |
|------|------|
| 스킬 6개면 무한 생존 | 하루 순수지가 양수 (회복 총량 > 소모) |
| 특정 빌드가 8배 오래 삼 | 아이템 무한구매로 경고 예산을 안 씀 |
| 백수 엔딩이 한 번도 안 나옴 | 회차가 짧아 "3회 미납"에 물리적으로 도달 불가 |
