# 배경음악 자리

`bgm.mp3` 를 이 폴더에 넣으면 게임에서 바로 켜진다 (경로는 `index.html` 의 `SND.bgm`).
파일이 없으면 설정 탭에 "음악 파일 준비 중" 으로 뜨고 조용히 넘어간다.

- 파일명은 영어로. 한글 파일명은 배포하면 404 가 난다 (NFD/NFC)
- 1~2분짜리 반복용 곡, 1~2MB 이하 권장
- 라이선스: 저장소가 Public 이라 **음원 파일 재배포가 허용**돼야 한다.
  CC0 가 가장 안전. CC-BY 면 아래에 출처를 적는다.
  "영상 배경음악으로만" 조건인 곡은 넣으면 안 된다.
